# Проект первого спринта на курсе мидл-фронтенд разработчик

## Технологии

- Handlebars
- Typescript
- Vite
- Netlify

## Запуск

Режим разработки
`"dev": "vite",`

Сборка
`"build": "tsc && vite build",`

Запуск собранной версии
`"preview": "vite preview",`

Сборка и запуск одной командой
`"start": "tsc && vite build && vite preview"`
